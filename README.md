## Project Description
A comprehensive Currency Converter GUI application built with Python and Tkinter. The application fetches real-time exchange rates from an external API, allows currency conversion between multiple currencies, and maintains a history of all conversions.

## Features
- Real-time currency exchange rates via external API
- Support for over 160 currencies
- User-friendly graphical interface
- Conversion history with automatic saving
- Export/import history as JSON
- Input validation for amounts
- Clear and intuitive design

## How to Get an API Key

### Using ExchangeRate-API (Recommended)
1. Visit [ExchangeRate-API](https://www.exchangerate-api.com/)
2. Sign up for a free account (no credit card required)
3. Verify your email address
4. Navigate to your dashboard to find your API key
5. Copy the API key

**Free Tier Includes:**
- 1,500 requests per month
- Real-time exchange rates
- Support for 160+ currencies
- No credit card required

### Alternative Free APIs
- **Frankfurter API**: No API key required (limited features)
- **CurrencyAPI**: Free tier available
